# Product specification — v0.2

## Product definition
A personal human-rhythm observatory that synchronizes observations from nine domains against one temporal axis, from a single day to a lifetime.

## Core experience
The default page is the Rhythm Map. It shows all available domain series on a shared x-axis. A user selects a temporal window and can inspect raw points and their provenance.

## Domains
1. Biological & circadian
2. Physical
3. Emotional
4. Cognitive
5. Behavioral
6. Social
7. Environmental
8. Occupational & time use
9. Meaning & recovery

## Temporal windows
Today; 9 days; 1 week; 1 month; 3 months; 6 months; 1 year; 2 years; lifetime; custom range.

The selected window changes the visible date range, not the underlying observations. Data aggregation must be explicit and must never manufacture missing values.

## Current state
"Current" is defined as the latest recorded observations per domain. It is not live physiology, sensor telemetry or a prediction.

## Data semantics
- Raw observations are the source of truth.
- A rating of 1–5 can be mapped to 0–100 for display only.
- Reverse-coded items are inverted only in the display transform; raw values remain unchanged.
- Values in minutes or hours remain in their native units.
- Missing values remain missing.
- Every observation retains source, timestamp, confidence and notes.

## Lifetime view
The lifetime axis can begin at birth, but measured domain history begins only when data are available. Retrospective periods and events provide context and must be labeled as recalled.

## Persistence
Local SQLite for single-user development. Supabase PostgreSQL is the intended hosted persistence layer. Authentication and Row Level Security must be tested before multi-user or public private-data use.

## Acceptance criteria
- The Rhythm Map is the home page.
- Nine domains can be plotted on a shared time axis.
- Temporal selectors include all specified ranges.
- A timestamped check-in creates raw indicator records.
- A retrospective life phase records date interval and recall confidence.
- A life event records date, context and potentially affected domains.
- Export includes observations, life phases, events and activities.
- UI clearly distinguishes display transformations from validated scores.
- No fake historical or sensor-derived data are created.
